# Sales & Demand Forecasting Project

## Overview
This Machine Learning project predicts future sales using historical business data.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

## Features
- Data Cleaning
- Feature Engineering
- Sales Forecasting
- Error Evaluation
- Visualization

## Machine Learning Model
Linear Regression

## Results
The model predicts future sales trends to help businesses:
- manage inventory
- improve planning
- reduce losses
